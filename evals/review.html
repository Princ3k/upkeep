Every identifier below was found by some runs and missed by others.
    Each one is either a real change one run missed, or something a run read into the
    document that is not there. No automatic check can tell those apart.

    
Judge against the quoted source, not against the runs. In the guide counts
    it as a real change that the other runs missed; not in the guide marks it an
    over-read.

    
Same change, different name is the third option and, in practice, the most
    common. Runs routinely record one change under different labels — graphql-client
    against GraphQL client, or a method against the class holding it. Nobody
    missed anything, so these are excluded from recall rather than counted against whichever
    run spelled it differently.
